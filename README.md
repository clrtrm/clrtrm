# Hello, I'm Clara! 👋
- I'm **Clara** (she/her), a Ruby on Rails / React.js fullstack developer based between Paris and Dijon, France.

- My coding journey started with **[The Odin Project](https://www.theodinproject.com/about)** (a self-paced online curriculum that is entirely free and open source) and **[La Capsule](https://www.lacapsule.academy/formation-developpeur-web/full-time)** (a 10-weeks on-site bootcamp). Before that, I studied international management and worked non-technical positions at the scale-ups **COMATCH** (now **[Malt Strategy](https://en.malt.fr/c/maltstrategy)**) and **[Shine](https://www.shine.fr/)**.

- After 3 years working as a React.js Frontend Engineer at **[MWM](https://mwm.ai/)** 🥁 and a short break pursuing my passion for specialty coffee, getting my driver's licence and learning Ruby on Rails, I'm now looking for my next role as a RoR backend / fullstack developer.

As of July 2026, I'm building Prompto, my ✨ ultimate RoR / React.js portfolio piece ✨ before applying for my next adventure. 🚀
